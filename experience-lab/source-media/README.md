# Source media for the LESNAR AI homepage

Real captures and source-backed specifications. Nothing here is generated,
mocked up, or illustrated from imagination.

The pipeline this feeds: real system, real capture or data, Higgsfield
enhancement or explanatory motion where it genuinely helps, then integration.
This directory owns the first part and defines what the third part is allowed
to do.

```
medimatch/  six real interface captures at 3x, provenance, Higgsfield manifest
sentinel/   capture plan, blocked on one driver command
simy/       architecture visual specification, source-backed, no footage needed
```

## State on 29 September 2026

- **MediMatch:** done. Six states captured from the live application at 3x DPI,
  zero page errors, one coherent scenario across detect and route.
- **Sentinel:** blocked. Gazebo cannot render until the NVIDIA module is rebuilt
  for kernel 7.0.0-34. The plan is written and the poses are chosen, so capture
  starts the moment `nvidia-smi` answers.
- **Simy:** no footage is wanted or honest. The trust architecture is the
  subject and every element of it is tied to a file in the repository.

## Rules that travel with this material

- Real interface, spatial transition, real interface. Never screenshot to AI
  remake.
- No digit, place name or label may be altered by any downstream tool.
- Disclosures attached to prototype material keep their meaning wherever the
  material appears.
- Where a system has not been flown, deployed or audited, the media must not
  imply otherwise.
