# LESNAR AI — growth plan, from November 2026

Goal: lesnarai.com brings in enquiries from organisations commissioning software, and each enquiry
arrives already trusting the work. No paid advertising and no changes to external accounts without
the owner's approval. No thin keyword pages, invented testimonials or claims ahead of evidence.

## 1. What is in place (26 Nov 2026)

- `lesnarai.com` is canonical; the Google Business Profile is categorised as a software company.
- Structured data on Home (Organization and WebSite: Nairobi, contact, founder, fields of work).
- Page titles carry the terms buyers search for: custom ERP, software, AI and security engineering.
- Home leads with systems running for real users (BizMtaani, CarePro), then security, health data
  and autonomy. Every card has a description that phone visitors can read.
- Direct email and WhatsApp on every page. The enquiry form goes live once delivery is confirmed (D-48).

## 2. Search intent, mapped to pages that already exist

Deepen these pages rather than adding new ones.

| Intent | Page | What makes it rank and convert |
|---|---|---|
| custom ERP / organisational software, Kenya | `/capabilities/` | Named disciplines, real proof per discipline, limits stated |
| software development company, Nairobi | Home, `/company/` | Organization data, founder accountability, live systems first |
| ordering and payments for bars, restaurants and shops (M-Pesa) | `/work/bizmtaani/` | The rules it enforces, live captures, architecture |
| health platforms / home care software | `/work/carepro/` | Verification gate, journey, security design, honest maturity |
| cybersecurity engineering / security operations | `/work/sentinelcore/` | Blind-tested decisions, coverage, governed containment |
| start a software project | `/start/` | What to bring, what changes the price, direct contact |

## 3. The next 30 days (owner actions marked ●)

1. ● **Search Console.** Verify `lesnarai.com` (a DNS TXT record, or an HTML file the site can
   serve; send the token and it ships the same day). Submit `sitemap.xml`, then request indexing
   for Home, Capabilities, Work and the two refreshed case pages.
2. ● **Google Business Profile.** Website `https://lesnarai.com/`; services named as on
   Capabilities. Each month, post one case-page link with one engineering decision explained.
   Ask real clients for reviews, with no incentives.
3. ● **Client permission.** Ask the security company and the optician for written publicity
   approval. A named, working client system is worth more than any page we can write. The named
   material is ready, held privately (D-45).
4. **LinkedIn**, the company page and the founder. One post per case study, each explaining one
   real decision: why a tab cannot close with money outstanding, why patient details stay hidden
   until a nurse accepts, why security decisions are tested blind. Link to the case page. Keep
   the name, phone and address identical to the Business Profile.
5. **GitHub.** Public repositories link back to their case pages, and private client code stays
   private. The profile README states what LESNAR AI builds and links to `/work/`.
6. **Technical demonstrations.** Short screen recordings made with the existing capture pipeline:
   a BizMtaani order from menu to station ticket (demonstration mode, sample data) and the CarePro
   verification gate. Publish on LinkedIn and link the case page.
7. **Referrals.** After each delivered engagement, ask the client for one introduction to an
   organisation with a similar problem, and record where every enquiry came from.

## 4. What to measure, monthly

- Enquiries by channel (form, email, WhatsApp) and by source (search, LinkedIn, referral, direct).
  Ask "how did you find us" in the first reply rather than tracking visitors; the site has no
  tracking by design.
- Search Console clicks and queries for the intents in section 2.
- Conversations that reached a written scope, and scopes accepted.

## 5. Not doing

- Paid advertising, until enquiries from organic channels show which message converts.
- Location or keyword pages without distinct substance.
- Testimonials, logos or client names without written permission.
